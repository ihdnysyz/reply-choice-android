探针报告“接入：开启，监听：已连接，解析异常：0，历史重放：0”。用户随后澄清本轮保持 QQ 开启，测试对象是 QQ；因此微信 0 回调不能用于评价微信兼容性。
QQ 可读不等于联系人身份可可靠绑定。当前没有结构化 sender / shortcutId；不得只凭通知标题或昵称自动套用联系人关系历史。
0.1.1-probe 在诊断报告中增加 QQ 通知键与标题的匿名聚合计数。用户目前只有一个 QQ 发送账号，无法做两联系人隔离测试；该计数本身也不足以证明身份可可靠绑定。0.2.0-alpha 因此只采用当前消息和本次选择的关系，自动 QQ 模式一律使用未知关系。
